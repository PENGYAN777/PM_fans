# `data/` — inputs and digitised points

| File | Content | Source |
|---|---|---|
| `table1_mm_conditions.csv` | six operating conditions of Table I (`Z9`…`Z4`) | this work |
| `cramer1992_toluene.csv` | Toluene case of Cramer & Crickenberger (1992) | digitised from the published figure |
| `gajoni2026_experiment.csv` | experimental `M2(θ)` and `P2/P1(θ)` for MM | digitised from Gajoni et al. (2026), *JFM* **1028**, A41 |

Every file carries a header comment with the source, the digitisation uncertainty and the units.
Files are written by the scripts in `II/C` where possible, so that the digitiser is auditable.
